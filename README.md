# Wildberries Parser

Парсер товаров с маркетплейса Wildberries. Позволяет парсить категории, магазины или бренды. Собирает всю собранную информацию в оформленный Excel файл.

![Preview](https://github.com/user-attachments/assets/f587e7dc-206a-4d6b-995b-4cf47432cbce)

## Возможности
- Сбор данных по категориям товаров или по конкретным ссылкам на магазины/бренды.
- Автоматический обход антибот-систем Wildberries.
- Сохранение результатов парсинга в красивый Excel-файл с картинками товаров.

## Обход защиты
Парсер использует комбинированный подход для извлечения данных, что позволяет эффективно обходить антибот-защиту Wildberries:
1. **Эмуляция реального браузера**: Для сбора детальной информации (особенно при парсинге по магазинам и брендам), которая защищена от прямых запросов, используется **Playwright Chromium**. 
2. **Имитация поведения пользователя**: Браузер загружает реальные страницы, выполняет JS-скрипты, что делает парсинг неотличимым от действий обычного покупателя.
3. **Открытое API**: Часть информации (например, дерево категорий) собирается напрямую через официальное API Wildberries, когда это доступно и не блокируется.
